# Chat webfont sources

These unmodified WOFF2 files are self-hosted with the app. Each font uses the SIL Open Font License 1.1; the original copyright notices and complete licenses are shipped from frontend/public/font-licenses/chat/ so they are included in production builds. No font service is contacted at runtime.

Retrieved from the official Google Fonts service on 2026-11-11. Each file is normal style, weight 400. Latin and Latin Extended subsets are included; other scripts use the application's fallback fonts. The upstream Rajdhani Devanagari and Space Grotesk Vietnamese subsets are not bundled.

[Google Fonts CSS request](https://fonts.googleapis.com/css2?family=Oxanium:wght@400&family=Rajdhani:wght@400&family=Space+Grotesk:wght@400&display=swap)
